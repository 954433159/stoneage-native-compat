## 首次构建中修正的问题

- 首次完整构建完成编译与客户端准备后，最后一步因导出清单遗漏 `verify_prepared.py` 失败。补齐清单后该步骤通过，并新增分发完整性回归。没有把首次命令记录为全程一次成功。
- 独立端口启动试验首次因测试脚本将配置写成CRLF而使SAAC连接失败。恢复生成器使用的LF格式后启动成功；运行说明已明确该限制。
- Gitleaks初次6条报告对应输入锁内的SHA-256字段名误报。将锁格式改为明确的`path`/`sha256`记录后重新扫描，未屏蔽规则。
